A collection of **Python beginner projects** built during the Codesoft internship program. Each task demonstrates core Python programming concepts including data structures, file handling, and control flow.

---

## Projects

| Task | Project | Concepts Used |
|---|---|---|
| Task 1 | To-Do List | Lists, loops, user input |
| Task 2 | Calculator | Functions, conditionals, math operations |
| Task 3 | Password Generator | Random module, string manipulation |
| Task 4 | Rock Paper Scissors | Randomization, game logic, conditionals |
| Task 5 | Contact Book | Dictionary, CRUD operations, file I/O |

---

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/SushantSharma4/Codesoft.git
cd Codesoft
```

2. Run any project:
```bash
python Task1_ToDoList_.py
python Task2_Calculator_.py
python Task3_Password_generator.py
python Task4_Rock_Paper_Scissors.py
python Task5_Contact_Book.py
```

- Working with built-in Python modules (random, string)
